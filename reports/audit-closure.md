## 明确不混入本轮的扩展

旧 V13 的评分撤回、易混对照、手动推迟、任意条目编辑/删除属于另一个有数据语义影响的开发范围，原报告也明确“产品缺口，不是这次按钮点错”。本轮没有冒充已实现它们；教材差异修订只解决有来源、稳定 ID 的教材更新。没有引入 AI 评分、预测掌握度、改记忆公式或新的统计系统。

## 验证与实际边界

- 最终完整发布通过：16 个测试文件、113 项单元测试，类型检查、单文件构建、`verify-fusion`，52 个浏览器场景。`fusion-file-check.json` 为 `scope: full`、零非预期脚本错误与零额外外部请求；局部排查报告不能代替该结果。
- `dependency-audit.json` 和 `dependency-runtime-audit.json` 当前均 0 告警。移除存在告警且无安全升级版本的 singlefile → micromatch → braces 链，新增受约束单入口内联打包器，未降级规避扫描。
- 压力夹具：500 题、5000 条日志、约 1.8 MB JSON，1667 个模拟日期；4 倍 CPU 限速，20 次逐字输入，测启动、搜索、序列化与 setItem。每次都校验最后草稿落盘，不是真实使用了 1667 天。原始结果见 `performance-audit.json`，硬件噪声下不宣称稳定加速。
- 当前量级尚无必须改数据库的证据，但同步写入会随数据增长变慢、也受 localStorage 配额约束；测量不能证明无限历史无卡顿。保留下载备份与写失败提示，没有把持久化延迟到关闭窗口。
- 本环境 Chromium 管理策略禁止 `file://`。完整流程通过本地 HTTP 提供同一个发布 HTML，运行时零额外外部请求。不是本地文件实机认证，也没有绕过浏览器管理策略。
- 已测试同源双窗口竞争和完整 Chromium 进程关闭、同一磁盘用户目录重启。新锁只协调遵守协议的新版同源窗口；旧程序、不同来源、不同浏览器/文件路径不能据此声称同步。升级时应关闭旧版。
- Windows Edge、华为、Safari、读屏及低端实体设备未实测，保留后续实机清单。无障碍测试只覆盖部分语义、焦点与危险按钮计算色，不宣称全面通过。
- 冻结 HTML、管理学来源 hash/itemId/schemaVersion/contentVersion、Recall/Evidence/Schedule/FSRS 保护校验不变。用户明确选择教材修订时，通用题目可以更新其来源字段；这与静态管理学教材基线未改不是一回事。
