当前分支：`feat/physiology-textbook`，基于界面审计版 `c7c5f9b`。本次只接入用户提供的资料与必要的教材导入适配，沿用原346三主题界面和训练引擎。

## 接入内容

原稿共 **8章60题**，其中 **56题进入训练，4题仅供查询**。四题包含“内容待补充”，具体清单及逐章数量见 [physiology-import.json](physiology-import.json)。部分题号跳号、题目跨章节归类均按原稿保留，不重新编号或自行移动。

- 按 `##` 识别章节、`###` 识别完整题目、`####` 提取原文核对小标题。
- 一题对应一次主动提取任务，未拆成普通词语闪卡。
- 原始 Markdown 逐字节归档到 `sources/physiology/运动生理学-最终版.md`；Git 属性禁止换行转换，以保持源文件 hash。
- 题目正文仅将 CRLF 换成 LF、去掉题目边界空行；没有增删正文、自动生成论证、举例或纠错。文件中的“问AI”等文字视为原稿内容，不作为执行指令。
- 开篇说明与第八章章前流程保留在资料库。原稿的知识准确性未在本次接入中审核；“最终版”沿用用户文件名。
- 生理学源文件 SHA-256：`c564ce8c768d3311b582c0b3be5dfd3b47511d85111546b903d17526f79700e6`。

## 在程序中使用

新版 HTML 已内置资料，无需额外下载 JSON 才能开始。进入「资料库 → 运动生理学」，可以按8章筛选，查询原文及待补充题。今日教练在原预算、科目权重和新学配额内安排56道完整题；4道待补充题不参与自动新学、到期或等待复测计算。

核对清单是原稿小标题，用于用户自行核对输出骨架，不代表程序已自动评定答案正确或细节齐全。训练仍使用通用模块的闭卷草稿、揭晓后冻结、自评和原FSRS调度。

已有用户的当日章节范围、已分配预算和当前任务保持原样，新增题不强行挤入已锁定的章节范围；若当日配额已完成，可次日继续。

## 数据兼容

教材是追加资料，不是用户成绩备份。稳定题目 id 由教材包标识、原章节和原题名生成；正文修订不参与 id 生成。本次不会修改管理学 itemId、sourceHash、schemaVersion 或 contentVersion。

首次打开新版、恢复接入资料前的旧整包时，补入缺少的生理学条目；保留所有同 id 旧题的正文、评分、dueDate、日志、当前草稿和任务预算。旧版导入教材后再次导出的个人记录若仍带教材格式标识，本版会识别已有评分或日志，按学习记录合并，避免把历史误当作纯教材丢弃。

安装标记随 `general.installedTextbooks` 保存在原平台数据中，刷新不反复新增。不会按相同题名强行合并其他来源的旧题，以免错接学习证据。

`346_Physiology_Import.json` 是独立教材资料文件：本版识别 `346-textbook` 格式，重复导入只补缺项，已有记录不覆盖；该文件也可在进行中训练时安全追加。

为兼容前一版融合程序，文件的 `points` 包含56道完整题，4道待补充题保存在 `referencePoints` 附录。本版将两部分一并展示；旧版仅显示56题，附录保存在扩展数据中。**旧版通用 JSON 导入仍采用同 id 覆盖规则，不具备本版的教材重复导入保护；已有记录建议导出旧整包后在新版恢复。**

新版恢复旧空数据时，学习日志为空，内置教材仍作为未训练内容存在。教材安装不计作训练、不生成 Attempt 或 ReviewLog。
