# 当日科目选择与资料库自主训练

日期：2026-10-18。分支 `feat/daily-subject-practice`，基于离线评审版 `a8c1632`，旧发布分支和冻结产物保留。

## 本次实现

- 首页提供自动安排（默认）与多科目选择，显示当前选择和未选科目到期提醒；选定范围无题时明确等待/完成，不回退到别科。
- 当天选择随刷新和整包备份保存，按设备本地日期次日重置。切换范围保留未完成稿、已开始任务和预算。
- 两种资料库提供章节练习与可训练单题入口。章节选择完整章节而非搜索命中的部分题，预览显示第一题、题量、预计时间；优先到期题，其次未训练题。
- 自主范围允许越过自动科目筛选和新学/章节配额，仍计入同一任务账本、预算和新学数量。原 Recall / 评审 / Evidence / Schedule / 通用 FSRS 保存入口复用。
- 单题允许提前复习，开始前提示；开始不更改到期日，实际完成后由原引擎重新调度。
- 参考资料、旧管理学查询记录、已作为A提示的纯B骨架不派题。纯B专题等原本可独立训练的内容仍可练。
- 本次范围有限，完成题移出，结束后不自动切章/换科。预算不足先停止，额外练习须明确确认追加分钟数；最高600分钟，不改明天的默认预算。
- 未完成任务不可覆盖；保存失败不产生假成功，确认框可取消；手机选择区用摘要收起，让开始按钮保持突出。

## 数据兼容与实现文件

新增 `FusionDay.subjects?: string[]` 与 `practice?: {module, kind, title, itemIds}`；无字段的旧数据仍按原自动安排读取。`itemIds` 保存本次待练范围，完成后移除，不复制题库或成绩。原版本号、Attempt和通用日志结构不变；新增字段沿原全科整包导入导出，校验非法/重复/空的科目选择和异常练习范围。

修改 `src/fusion/{types,planner,transfer,store,components,FusionApp,memory-theme.css}`、全科 Today/Next/Library、管理学 Library；新增选择单测和浏览器流程，更新发布脚本及使用说明。没有引入依赖、服务器或网络调用，没有调整教材正文及学习算法。

次日不续接昨日章节队列，只恢复正在作答的题；教材被删除或变成参考项时不继续派发该题。旧版程序本身不理解新增选择字段，升级后使用本版继续训练；完整备份仍保留原作答证据。

升级前导出旧版全科备份并关闭旧版，再打开新版恢复。不要把零记录基线覆盖到已有学习记录上。学习内容的准确性和离线文字评审的语义局限不因这次入口改造而改变。
