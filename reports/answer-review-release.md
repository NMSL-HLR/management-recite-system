# 离线答题评审：实现与验收

日期：2026-10-15。分支 `feat/offline-answer-review`，基于 `5371f62` 的 PDCA 修复版。原版本与冻结产物保留。本版满足不购买 API、使用手机手写识别后粘贴、保持单文件离线运行的约束。

## 实际能力

- 管理学、运动生理学、体育概论：交卷冻结后自动对照当前题目，不在闭卷草稿或撤提示复述阶段泄露教材。
- 管理学使用原 checkpoint ID 与原文；通用科目依据唯一的清单标题定位对应正文，遇到歧义明确回退人工。没有清单时可查看整题对照，但不会凭空增加评分点。
- 展示“找到原文对应 / 有相关表述 / 需要检查 / 未找到明确对应 / 请直接核对原文”，并列本人原句和教材依据。没有正确率、记忆概率或考试分数。
- 核对数值、比较符、运算符、离子符号、方向词、否定词差异；它们是需复核的线索，不是已证实错误。源文同时有相反方向时提醒核对对象配对。
- 单项确认、取消确认、批量清单预览与应用；只有本人操作才调用原核对保存入口。体育案例不同于原文时仍可人工确认，匹配不自动判定体育例证完整。
- 原核对列表保持可用，管理学继续撤提示复述，通用科目仍自行选择评级。闭卷考试仅在揭晓后显示只读评审，不生成学习成绩。
- 手机长按粘贴指导、窄屏交卷后定位、可复制/下载的 TXT 报告。剪贴板权限拒绝时显示可手动复制文本。照片识别由手机系统完成，本程序不调用华为私有接口。

## 实现边界

这是确定性的本地文字对齐与规则提示，没有下载或运行大语言模型。完全相同或相似的词句不能证明对象、语义、因果和事实正确；同义改写也可能未匹配。标题匹配仅说明骨架出现；正文仍分开核对。未匹配项不自动认定为错漏。

格式归一化只用于匹配，不改写冻结稿、教材或科学符号；显示完整原稿与来源。来源不明确时拒绝猜测。输入超过 20000 字符、450 片段、100 核对点、单点原文 8000 字符、总原文 40000 字符或预计 120000 次片段对照时停止自动匹配，保留原核对流程；不截断已保存的答案。

复审特别修复了中文标点归一化污染引用、科学符号被当作装饰删除、无清单的同级章节被错误归到上一核对点等问题。对小数、正负号、除号、离子电荷和方向箭头加入回归。旧浏览器测试清除搜索后未等待延迟列表更新，补齐明确的完成条件，未放宽断言。

## 数据与文件

没有新 schema、Attempt、日志或迁移格式。评审结果由冻结草稿和当前教材重算；确认项使用原 checkedPointIds / checkedLabels，经原 Evidence、Schedule、FSRS 处理。无新增网络请求、服务器或依赖。需要固定保留某次派生报告时导出 TXT。

新增 `src/review/{types,text,rubric,analyze,report}.ts`、`review.css`、`src/components/AnswerReview.tsx`。接入 `src/views/Recall.tsx`、`Exam.tsx`、`src/fusion/views/GeneralTraining.tsx`。新增单测和浏览器流程，更新打包器、说明与产物；原教材、引擎及冻结 HTML 均保持保护校验。

## 验收结果

- 完整发布流程通过：18 个单测文件、160 项单测；62 个浏览器场景，`fusion-file-check.json` 为 `scope: full`。
- 浏览器报告无额外外部请求、无非预期脚本错误；覆盖冻结前隐藏、保存失败、刷新恢复、报告下载、320/390/768px 布局、原证据与调度、考试只读等。
- TypeScript 检查、单文件构建、14 个原 MRC 保护文件、原教材（仅构建时间不同）、FSRS 核心和冻结产物校验通过。sourceHash、itemId、schemaVersion、contentVersion 未改。
- 完整源代码 ZIP 在独立临时目录安装锁定依赖并重新构建、通过保护校验；重建 HTML 除教材构建时间外逐字一致。下载 ZIP、源码 ZIP 中的 HTML 与发布 HTML 字节一致。
- 本次 npm audit 全依赖和运行依赖均为 0 告警。性能样本见 performance-audit.json；同样 4 倍 CPU 限速夹具下启动 928→934ms，输入到两帧 p95 170→174.4ms，属于本次合成环境观测，不代表鸿蒙实机。
- 制品证据见 answer-review-artifact-check.json。局部 review-only 报告不算完整发布。

## 仍需如实说明

- 云端禁止 file://，浏览器回归通过 HTTP 加载同一离线单文件，零额外外部请求。未实测用户的 Pura X / HarmonyOS 7.0、实际系统识字、鸿蒙下载器和长按粘贴；320/390/768px 仿真不能替代实机。
- 没有衡量用户真实手写答案的识别或语义评阅准确率。通过软件测试不等于老师阅卷准确率。
- 评审报告会随规则/当前教材重算，原历史证据不被重写。已确认要点仍依赖本人判断，不能把看答案后的补写当作闭卷输出。
- 历史全科记录可沿原入口恢复；先导出旧版备份并关闭旧版，再打开新版，勿再次导入零记录基线覆盖已产生的学习记录。
