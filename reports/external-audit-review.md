# 外部审计复核与修复

基于仓库整理版 `88fe351`，修复分支 `fix/audit-leaks-preface`。按可读源码和实际数据复核，压缩函数名随构建变化，不作为稳定定位依据。

## 1. 遗漏项日期：确认并修复

`src/general/data.ts` 的 `reviewGeneral` 会给再次遗漏的要点重设明日日期。现在未解决的旧遗漏保留原截止时间，仅首次遗漏设置为下一天；本次勾选的要点移除。按 label 去重，历史重复项保留最早日期，不改历史日志中的 previousState，也不修改传入对象。

需要区分影响范围：当前教练选题依据整题 `dueDate`，没有根据 `leaks[].due` 单独派发补漏任务。因此这是遗漏记录被推迟的真实错误，但不能据此认定原 FSRS 计算本身有误。此次不引入新的补漏调度规则，不改变整题间隔。

既往已经被覆盖的日期不做猜测性回填；修复保证之后不再推迟仍未解决的遗漏。历史记录保留原样。

## 2. 序言实体显示：确认并修复

原稿本身含 `&gt;`，React 文本节点不会自动解码。仅在 `physiologyPrefaceText` 展示值中把这一引用符号还原成 `>`，继续使用安全的文本渲染，不启用 HTML 注入。原始 Markdown、内置教材 JSON、导入包和 sourceHash 不变。浏览器回归检查展开说明后的真实 DOM 文本。

## 3. 自动安装少四题：当前版本不成立

- `src/data/physiology/physiology.json` 的 `points` 本身就是60题，含4道 trainingBlocked 参考题。
- `src/general/textbook.ts` 自动安装读取的是上述内置文件。
- 独立的 `346_Physiology_Import.json` 为兼容旧版才分为56道 points 加4道 referencePoints；当前导入器合并两者。

现有单元测试及 file:// 新用户回归验证安装60题、训练候选56题、资料库可查4道待补充题，无需重复追加。

## 4. 章节范围不自动刷新：既定规则

`lockChapters` 刻意锁定当日新学章节，避免新增资料或完成旧题后无限扩大新学范围。到期复习不受该范围限制。新科目可建立范围；已锁科目的新章节默认次日参与。

用户修改科目策略会通过 `setPolicy` 清除该科目的章节选择并重算；章节上限0表示不限制章节。不能直接合并全部新章节，否则可能绕过用户设置的上限。这次不更改计划规则。

## 5. 其他观察

- 主题切换后保存失败的提示准确区分了“当前窗口生效”和“未持久化”，不是主题状态错误，保留。
- `Alt+D` 等组合键可能被浏览器或系统优先截获；页面已有 preventDefault，但无法保证拦截系统级快捷键。页面按钮仍可完成操作，此兼容性限制保留。
- 存储写入及回滚失败已有恢复日志和 needsRecovery 路径。此前故障注入回归继续通过，但不据此宣称极端存储故障、多窗口并发或浏览器进程崩溃已获得完全保证。
