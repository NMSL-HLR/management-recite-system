# 346 记忆引擎 · 全部源码合并（v7.3）

## AGENTS.md

```markdown
# AGENTS.md —— 给迭代者的项目简报（Codex 请读）

## 这是什么

北大体育硕士（346）备考用的间隔重复复习应用。单文件离线交付：最终产物是 **一个 HTML 文件**，用户在手机浏览器（华为浏览器 / Edge）里离线打开，无网络、无账号、无后端。数据全部在 localStorage。

## 技术栈与构建

- React 19 + TypeScript + Vite + Tailwind 3.4 + HashRouter
- `vite-plugin-singlefile`：构建产物全部内联进 `dist/index.html`，交付即此文件
- 开发：`npm install` → `npm run dev`；构建：`npm run build`（勿改 build 脚本）
- 依赖里有完整 shadcn/ui（`src/components/ui/` 大部分未使用，属脚手架残留，可不动）

## 架构地图（改动从这几个文件入手）

| 文件 | 职责 |
|---|---|
| `src/lib/scheduler.ts` | **纯函数算法层**。FSRS-6（21 参数 W、DSR 模型、遗忘曲线、间隔求解）、目标保持率调度、科目交错 |
| `src/lib/store.ts` | 唯一状态入口。localStorage 读写、旧数据迁移（migratePoints）、评分/撤回/推迟/补漏/归档全部经此 |
| `src/types/index.ts` | KnowledgePoint 等类型，字段均有注释 |
| `src/pages/` | TodayPage（复习流，最重）、LibraryPage（知识库）、AddPage、StatsPage |
| `src/lib/subjectColors.ts` | 科目配色（哈希默认 + 用户覆盖） |
| `src/lib/naturalSort.ts` | 章节自然排序（中文数字） |
| `src/index.css` | 三套主题 CSS（neo 灵像素 / hmos 通透 / gba 像素）+ 移动端防缩放防护 |

## 不可违反的硬约束

1. **单文件离线**：不得引入需要网络的资源（CDN、网络字体、外链图片）。
2. **localStorage 键不能改名**（`ms346_*_v1`），否则用户手机上的学习数据全丢。新增字段走 `migratePoints` 迁移，旧数据必须无损升级。
3. **FSRS-6 参数 W 是官方默认值**（awesome-fsrs Wiki），除非用户明确要求不要改。
4. 移动端兼容三件套不能删：viewport 锁缩放（index.html）、`text-size-adjust:100%`、自定义 `desktop: (min-width:1024px) and (pointer:fine)` 断点（华为 Pura X 16:10 折叠屏踩过三轮坑）。
5. 日志有归档机制（活跃 2000 条上限，超出移入 `ms346_logs_archive_v1`），统计类功能注意这一分层。
```

## 已知测试局限

无头 Chromium 无法模拟 pointer:fine（setEmulatedMedia 无效），desktop 断点在无头环境永不触发；真实桌面浏览器该查询必为真。触屏视口已实测 pointerFine=false、保持移动布局。

## v6.1 补丁（华为浏览器比例问题二次修复）

用户实测 Pura X + 华为浏览器仍比例错误，追加两处修复：

1. **禁用文字自动放大**：index.css 全局 `text-size-adjust: 100%`（含 -webkit- 前缀）。华为/UC 等浏览器在宽屏下会擅自放大网页文字（text autosizing），是"缩放比例不对劲"的常见元凶。
2. **宽屏触屏容器加宽**：此前内容区在非桌面端一律限宽 512px（max-w-lg），Pura X 展开约 850px 宽时两侧大片空白、内容被压缩成细条。现在 md(≥768px) 断点放宽到 max-w-2xl（内容/顶栏）和 max-w-lg（底部导航），知识库网格 md 下三列。桌面端 desktop 断点规则不变（宽≥1024 且指针为鼠标）。

## v6.2 补丁（华为浏览器自动缩放）

截图发现页面加载后被华为浏览器放大约10%（卡片右缘被裁）。修复：viewport 加 maximum-scale=1.0/minimum-scale=1.0/user-scalable=no 锁定缩放；html,body 加 overflow-x:hidden + max-width:100vw 防横向溢出诱发缩放。

## v6.3 补丁（长标题被截断）

## v7 算法内核换代：SM-2 改良版 → FSRS-6（一步到位版）

依据 open-spaced-repetition/awesome-fsrs 官方 Wiki「The Algorithm」实现，非 npm 依赖（保持单文件离线交付）。

### 内核（src/lib/scheduler.ts 全量重写）
- **DSR 三变量**：难度 D∈[1,10]、稳定性 S（R 衰减到 90% 的天数）、可提取率 R
- **21 个官方默认参数**：`[0.212, 1.2931, 2.3065, 8.2956, 6.4133, 0.8334, 3.0194, 0.001, 1.8722, 0.1666, 0.796, 1.4835, 0.0614, 0.2629, 1.6483, 0.6014, 1.8729, 0.5425, 0.0912, 0.0658, 0.1542]`（约 7 亿条真实复习记录训练，单人用户直接用默认值即可，不要手调）
- **幂律遗忘曲线**：R(t,S)=(1+FACTOR·t/S)^(-w20)，FACTOR=0.9^(-1/w20)-1≈0.9804，保证 R(S,S)=90%
- **目标保持率调度**：间隔=S/FACTOR·(DR^(-1/w20)-1)；普通条目 DR=0.9，章节大条目（要点清单≥5 项）DR=0.95（复合结构衰减快，复习更勤）
- **公式组**：初始 S0(G)=w[G-1]；D0(G)=w4-e^{w5(G-1)}+1（钳制[1,10]）；D 更新=线性阻尼+向 D0(4) 均值回归；成功 S 增长（含 Hard 惩罚 w15/Easy 奖励 w16）；遗忘 post-lapse S 衰减且 min(S_f,S)；当天重学用短期公式 S·e^{w17(G-3+w18)}·S^{-w19}（G≥3 时不许降）
- **交错排序**：dueToday 按逾期排序后做同科目打散（interleaving）
- 旧字段 ef 冻结仅存档；LibraryPage 详情改显「难度 D · 稳定 S 天」

### 章节两级结构（要点清单 + 补漏队列）
- KnowledgePoint 新增 `checklist: string[]`（每行一个要点）与 `leaks: {label,due}[]`
- 录入页/编辑弹窗可加要点清单；复习页章节提示语改为「先在纸上默写本章框架，再逐条展开」
- 翻面后逐项核对：默认全「想起来」，点取消=漏掉；完整度自动映射建议评分（>95%秒杀/≥80%记住/≥50%模糊/<50%忘记，高亮推荐，可手动改）
- 漏项进入补漏队列（明天到期），今日页顶部红色补漏区单独攻克，「已掌握」移除
- 撤回快照扩展 difficulty/leaks，回滚完整

旧 EF∈[1.3,3.0] 映射 D∈[10,1]；S 下限保护；checklist/leaks 补空数组；importData 同样过迁移。已在 CDP 实测：旧 v2 数据（字符串 tags、无 FSRS 字段）加载→评分→撤回→补漏全链路通过。

## v7.1 任务量减负三件套

1. **推迟按钮**（store.ts postponePoint / 卡片右上「明天再看」）：不评分、不动 FSRS 状态，dueDate 顺延一天，用于"今天背不动这章"。

## v7.3 代码精炼（依据外部评审，已逐条核实）

1. **ef 死字段清除**：types 改 `ef?: number`（仅迁移读取）；createPoint/schedule/undo 快照不再写入。旧卡上的 ef 保留只读（迁移换算 D 用）。实测老卡 ef=1.8 → 迁移 D=8.24 → 评分调度正常。

3. 评审提到的"setHours 内联 6 处"在源码中不成立（仅 scheduler.ts startOfDay 一处，其余在其测试脚本/构建产物里），无需处理。
4. 评审的可选项"Recharts 换手写 SVG 省 150-200KB"**不采纳**：收益仅限体积、不影响运行，手写图表有回归风险，备考期不值得。

```typescript
import type { KnowledgePoint, Rating } from '@/types'

/**
 * 记忆调度引擎 —— FSRS-6（Free Spaced Repetition Scheduler v6）
 *
 * 现代间隔重复算法，Anki 25.x 默认调度器。核心为 DSR 三变量记忆模型：
 *   D (Difficulty)    难度 1~10，调节稳定性增长速度
 *   S (Stability)     稳定性：保持率 R 衰减到 90% 所需的天数
 *   R (Retrievability) 当前可提取率，随时间按幂律连续衰减
 *
 * 公式与 21 个默认参数来自 open-spaced-repetition/awesome-fsrs 官方 Wiki，
 * 默认参数在约 7 亿条真实复习记录上训练，单人用户直接使用即可。
 *
 * 调度思路：设定目标保持率 DR（默认 90%，章节大条目 95%），
 * 反解遗忘曲线 R(t)=DR 对应的时间 t 作为下次间隔。
 */

// FSRS-6 官方默认参数（open-spaced-repetition/awesome-fsrs Wiki "The Algorithm"）
const W = [
  0.212, 1.2931, 2.3065, 8.2956, 6.4133, 0.8334, 3.0194, 0.001, 1.8722, 0.1666,
  0.796, 1.4835, 0.0614, 0.2629, 1.6483, 0.6014, 1.8729, 0.5425, 0.0912, 0.0658,
  0.1542,
] as const

export const DAY = 24 * 60 * 60 * 1000

// 遗忘曲线形状常数：保证 R(S, S) = 90%
const DECAY = -W[20]
const FACTOR = Math.pow(0.9, 1 / DECAY) - 1

const clamp = (v: number, lo: number, hi: number) => Math.min(hi, Math.max(lo, v))

export function startOfDay(ts: number): number {
  const d = new Date(ts)
  d.setHours(0, 0, 0, 0)
  return d.getTime()
}

/** 幂律遗忘曲线：距上次复习 t 天后的预计保持率 (0~1) */
export function retrievability(tDays: number, stability: number): number {
  if (stability <= 0) return 0
  return Math.pow(1 + (FACTOR * tDays) / stability, DECAY)
}

/** 由目标保持率 DR 反解间隔天数（DR=0.9 时恰等于 S） */
function nextIntervalDays(stability: number, dr: number): number {
  return (stability / FACTOR) * (Math.pow(dr, 1 / DECAY) - 1)
}

/**
 * 目标保持率：章节大条目（要点清单 ≥5 项）复合结构衰减更快，
 * 提高到 95%（等价于复习更勤）；普通条目 90%
 */
export function targetRetentionFor(p: KnowledgePoint): number {
  return (p.checklist?.length ?? 0) >= 5 ? 0.95 : 0.9
}

/** 由要点完整度自动映射评分（章节复习时用） */
export function completenessToRating(completeness: number): Rating {
  if (completeness > 0.95) return 4
  if (completeness >= 0.8) return 3
  if (completeness >= 0.5) return 2
  return 1
}

/** 同科目打散：在保持到期优先的前提下，避免相邻两项同科目（交错效应，Rohrer） */
export function interleaveQueue(list: KnowledgePoint[]): KnowledgePoint[] {
  const rest = [...list]
  const out: KnowledgePoint[] = []
  while (rest.length > 0) {
    const prev = out[out.length - 1]
    const i = prev ? rest.findIndex((p) => p.subject !== prev.subject) : 0
    out.push(rest.splice(i >= 0 ? i : 0, 1)[0])
  }
  return out
}

/** 初始难度 D0：首次评分决定起点 */
function initialDifficulty(rating: Rating): number {
  return clamp(W[4] - Math.exp(W[5] * (rating - 1)) + 1, 1, 10)
}

/** 复习后难度更新：线性阻尼 + 均值回归（消除"难度地狱"） */
function nextDifficulty(d: number, rating: Rating): number {
  const delta = -W[6] * (rating - 3)
  const d2 = d + (delta * (10 - d)) / 9
  const d3 = W[7] * initialDifficulty(4) + (1 - W[7]) * d2
  return clamp(d3, 1, 10)
}

/** 成功回忆后的稳定性增长：难度越高/稳定越高增长越慢，越是濒临遗忘时答对增长越大 */
function stabilityAfterRecall(d: number, s: number, r: number, rating: Rating): number {
  const hardPenalty = rating === 2 ? W[15] : 1
  const easyBonus = rating === 4 ? W[16] : 1
  const inc =
    Math.exp(W[8]) *
    (11 - d) *
    Math.pow(s, -W[9]) *
    (Math.exp(W[10] * (1 - r)) - 1) *
    hardPenalty *
    easyBonus
  return s * (1 + inc)
}

/** 遗忘后的稳定性衰减（post-lapse） */
function stabilityAfterLapse(d: number, s: number, r: number): number {
  const sf =
    W[11] *
    Math.pow(d, -W[12]) *
    (Math.pow(s + 1, W[13]) - 1) *
    Math.exp(W[14] * (1 - r))
  return Math.min(sf, s)
}

/** 当天内重复复习的短期稳定性公式 */
function stabilitySameDay(s: number, rating: Rating): number {
  const inc = Math.exp(W[17] * (rating - 3 + W[18])) * Math.pow(s, -W[19])
  // 评分≥3 时稳定性不允许下降
  return rating >= 3 ? s * Math.max(inc, 1) : s * inc
}

/** 创建新知识点：录入当天即安排首次学习 */
export function createPoint(
  data: Pick<KnowledgePoint, 'subject' | 'title' | 'content' | 'tags' | 'checklist'>,
  now = Date.now(),
): KnowledgePoint {
  return {
    id: `kp_${now}_${Math.random().toString(36).slice(2, 8)}`,
    ...data,
    checklist: data.checklist ?? [],
    leaks: [],
    createdAt: now,
    difficulty: 5, // 首次评分后由 D0 公式重置
    interval: 0,
    repetitions: 0,
    stability: 0.4,
    dueDate: startOfDay(now),
    state: 'new',
    totalReviews: 0,
    lapses: 0,
  }
}

type SchedulePatch = Pick<
  KnowledgePoint,
  | 'difficulty'
  | 'interval'
  | 'repetitions'
  | 'stability'
  | 'dueDate'
  | 'state'
  | 'lastReviewedAt'
  | 'totalReviews'
  | 'lapses'
>

/**
 * 核心调度函数：根据本次回忆评分，按 FSRS-6 公式计算下一次复习安排。
 * 返回更新后的字段（不修改原对象）。
 */
export function schedule(p: KnowledgePoint, rating: Rating, now = Date.now()): SchedulePatch {
  const isFirstReview = p.totalReviews === 0
  const elapsedDays = Math.max(0, (now - (p.lastReviewedAt ?? p.createdAt)) / DAY)
  const sameDay = !isFirstReview && elapsedDays < 1

  // ---- 难度 D ----
  const difficulty = isFirstReview ? initialDifficulty(rating) : nextDifficulty(p.difficulty, rating)

  // ---- 稳定性 S ----
  let stability: number
  if (isFirstReview) {
    stability = W[rating - 1] // 初始稳定性 S0(G)
  } else if (sameDay) {
    stability = stabilitySameDay(p.stability, rating)
  } else {
    const r = retrievability(elapsedDays, p.stability)
    stability =
      rating === 1
        ? stabilityAfterLapse(p.difficulty, p.stability, r)
        : stabilityAfterRecall(p.difficulty, p.stability, r, rating)
  }
  stability = clamp(stability, 0.1, 36500)

  // ---- 间隔与状态 ----
  let interval: number
  let repetitions: number
  let state: KnowledgePoint['state']
  let lapses = p.lapses

  if (rating === 1) {
    // 完全忘记：当天重学（短期队列），间隔压缩
    repetitions = 0
    interval = 0
    state = 'relearning'
    lapses += 1
  } else {
    repetitions = p.repetitions + 1
    interval = clamp(Math.round(nextIntervalDays(stability, targetRetentionFor(p))), 1, 365)
    state = repetitions >= 2 ? 'review' : 'learning'
  }

  return {
    difficulty,
    interval,
    repetitions,
    stability,
    dueDate: startOfDay(now) + interval * DAY,
    state,
    lastReviewedAt: now,
    totalReviews: p.totalReviews + 1,
    lapses,
  }
}

/** 今日到期的知识点（含逾期），按逾期程度排序后做同科目交错 */
export function dueToday(points: KnowledgePoint[], now = Date.now()): KnowledgePoint[] {
  const endOfToday = startOfDay(now) + DAY - 1
  const due = points.filter((p) => p.dueDate <= endOfToday).sort((a, b) => a.dueDate - b.dueDate)
  return interleaveQueue(due)
}

/** 未来 n 天的复习负荷分布 */
export function upcomingLoad(points: KnowledgePoint[], days: number, now = Date.now()): { date: string; count: number }[] {
  const today = startOfDay(now)
  const result: { date: string; count: number }[] = []
  for (let i = 0; i < days; i++) {
    const dayStart = today + i * DAY
    const dayEnd = dayStart + DAY - 1
    const count = points.filter((p) => p.dueDate >= dayStart && p.dueDate <= dayEnd).length
    const d = new Date(dayStart)
    result.push({
      date: i === 0 ? '今天' : i === 1 ? '明天' : `${d.getMonth() + 1}/${d.getDate()}`,
      count,
    })
  }
  return result
}

/** 当前全库平均记忆保持率（模拟"现在抽查能答对多少"） */
export function averageRetention(points: KnowledgePoint[], now = Date.now()): number {
  const reviewed = points.filter((p) => p.lastReviewedAt)
  if (reviewed.length === 0) return 0
  const sum = reviewed.reduce((acc, p) => {
    const t = (now - (p.lastReviewedAt ?? now)) / DAY
    return acc + retrievability(t, p.stability)
  }, 0)
  return sum / reviewed.length
}
```

```typescript
import { useSyncExternalStore } from 'react'
import type { KnowledgePoint, ReviewLog, Rating, Tag } from '@/types'
import { DEFAULT_SUBJECTS } from '@/types'
import { createPoint, schedule, startOfDay, DAY } from './scheduler'
import { DEFAULT_TAG_COLOR, setSubjectColorOverrides } from './subjectColors'

const POINTS_KEY = 'ms346_points_v1'
const LOGS_KEY = 'ms346_logs_v1'
const SUBJECTS_KEY = 'ms346_subjects_v1'
const SETTINGS_KEY = 'ms346_settings_v1'
const SUBJECT_COLORS_KEY = 'ms346_subject_colors_v1'
const LOGS_ARCHIVE_KEY = 'ms346_logs_archive_v1'

// 活跃日志上限：超出后最旧的一批归档到独立存储区。
// 否则 logs 无上限增长，每次评分都全量 stringify，一年后会开始卡
const ACTIVE_LOGS_LIMIT = 2000
const ARCHIVE_CHUNK = 500

function appendLog(logs: ReviewLog[], log: ReviewLog): ReviewLog[] {
  const next = [...logs, log]
  if (next.length <= ACTIVE_LOGS_LIMIT) return next
  try {
    const archive = load<ReviewLog[]>(LOGS_ARCHIVE_KEY, [])
    localStorage.setItem(LOGS_ARCHIVE_KEY, JSON.stringify([...archive, ...next.slice(0, ARCHIVE_CHUNK)]))
  } catch {
    return next // 归档失败宁可保留，不丢记录
  }
  return next.slice(ARCHIVE_CHUNK)
}

export interface Settings {
  reviewCap: number // 每日复习上限（0 = 不限）
  newCap: number    // 每日新学上限（0 = 不限）
}

const DEFAULT_SETTINGS: Settings = { reviewCap: 0, newCap: 0 }

// 数据迁移：v1 tags(string[]) → v2 Tag[]；v2 → v3 补 FSRS 字段（difficulty/checklist/leaks）
// 加载时自动执行，保证老数据不丢
function migratePoints(points: KnowledgePoint[]): KnowledgePoint[] {
  return points.map((p) => {
    let out = p
    // v1 → v2：标签对象化
    if (!(Array.isArray(out.tags) && out.tags.every((t) => typeof t !== 'string'))) {
      const tags: Tag[] = (((out.tags as unknown[]) ?? []) as (string | Tag)[])
        .map((t) => (typeof t === 'string' ? { label: t, color: DEFAULT_TAG_COLOR } : t))
        .filter((t) => t.label)
      out = { ...out, tags }
    }
    // v2 → v3：FSRS 难度 D。由旧 EF 映射：EF∈[1.3,3.0] → D∈[10,1]，EF 越高难度越低
    if (typeof out.difficulty !== 'number' || Number.isNaN(out.difficulty)) {
      const ef = typeof out.ef === 'number' ? out.ef : 2.5
      const d = 1 + ((3.0 - ef) / 1.7) * 9
      out = { ...out, difficulty: Math.min(10, Math.max(1, Math.round(d * 100) / 100)) }
    }
    // 稳定性下限保护（FSRS 要求 S > 0）
    if (!(out.stability > 0)) {
      out = { ...out, stability: Math.max(0.4, out.interval || 0.4) }
    }
    if (!Array.isArray(out.checklist)) out = { ...out, checklist: [] }
    if (!Array.isArray(out.leaks)) out = { ...out, leaks: [] }
    return out
  })
}

interface StoreState {
  points: KnowledgePoint[]
  logs: ReviewLog[]
  subjects: string[]
  settings: Settings
  subjectColors: Record<string, number> // 科目名 → 调色盘下标
}

function load<T>(key: string, fallback: T): T {
  try {
    const raw = localStorage.getItem(key)
    return raw ? (JSON.parse(raw) as T) : fallback
  } catch {
    return fallback
  }
}

let state: StoreState = {
  points: migratePoints(load<KnowledgePoint[]>(POINTS_KEY, [])),
  logs: load<ReviewLog[]>(LOGS_KEY, []),
  subjects: load<string[]>(SUBJECTS_KEY, DEFAULT_SUBJECTS),
  settings: { ...DEFAULT_SETTINGS, ...load<Partial<Settings>>(SETTINGS_KEY, {}) },
  subjectColors: load<Record<string, number>>(SUBJECT_COLORS_KEY, {}),
}

// 科目颜色覆盖同步到配色模块（所有页面的 subjectColorClass 立即生效）
setSubjectColorOverrides(state.subjectColors)

const listeners = new Set<() => void>()

  localStorage.setItem(LOGS_KEY, JSON.stringify(state.logs))
  localStorage.setItem(SUBJECTS_KEY, JSON.stringify(state.subjects))
  localStorage.setItem(SETTINGS_KEY, JSON.stringify(state.settings))

export function reviewPoint(id: string, rating: Rating, missed: string[] = []) {
  const p = state.points.find((x) => x.id === id)
  if (!p) return

  // 评分前的完整调度状态快照，撤回时精确回滚
  const previousState: Partial<KnowledgePoint> = {
    difficulty: p.difficulty,
    interval: p.interval,
    repetitions: p.repetitions,
    stability: p.stability,
    dueDate: p.dueDate,
    state: p.state,
    lastReviewedAt: p.lastReviewedAt,
    lapses: p.lapses,
    totalReviews: p.totalReviews,
    leaks: p.leaks ?? [],
  }

  const patch = schedule(p, rating)
  // 漏掉的要点进入补漏队列：明天单独重现（章节框架不走整章重来）
  const kept = (p.leaks ?? []).filter((l) => !missed.includes(l.label))
  const tomorrow = startOfDay(Date.now()) + DAY
  const newLeaks = missed.map((label) => ({ label, due: tomorrow }))
  const leaks = [...kept, ...newLeaks]

  const log: ReviewLog = {
    id: `log_${Date.now()}_${Math.random().toString(36).slice(2, 6)}`,
    pointId: id,
    subject: p.subject,
    reviewedAt: Date.now(),
    rating,
    intervalBefore: p.interval,
    intervalAfter: patch.interval,
    previousState,
  }
  setState({
    ...state,
    points: state.points.map((x) =>
      x.id === id ? { ...x, ...patch, leaks, postponedUntil: undefined } : x,
    ),
    logs: appendLog(state.logs, log),
  })
}

    ...state,
    points: state.points.map((p) =>
      p.id === pointId ? { ...p, leaks: (p.leaks ?? []).filter((l) => l.label !== label) } : p,
    ),
  })
}

/** 今日到期的补漏项（跨知识点汇总） */
export function leaksDueToday(points: KnowledgePoint[], now = Date.now()): { point: KnowledgePoint; label: string }[] {
  const endOfToday = startOfDay(now) + DAY - 1
  return points.flatMap((p) =>
    (p.leaks ?? []).filter((l) => l.due <= endOfToday).map((l) => ({ point: p, label: l.label })),
  )
}

/** 撤回一次评分：知识点回滚到评分前状态，并删除该条日志 */

  const log = state.logs.find((l) => l.id === logId)
  if (!log) return
  setState({
    ...state,
    points: log.previousState
      ? state.points.map((p) => (p.id === log.pointId ? { ...p, ...log.previousState } : p))
      : state.points,
    logs: state.logs.filter((l) => l.id !== logId),
  })
}

/** 重命名科目：同步更新所有该科目下的知识点 */
export function renameSubject(oldName: string, newName: string): { ok: boolean; message: string } {
  const n = newName.trim()
  if (!n) return { ok: false, message: '科目名不能为空' }
  if (n === oldName) return { ok: false, message: '名称未变化' }
  if (state.subjects.includes(n)) return { ok: false, message: '该科目名已被占用' }
  setState({
    ...state,
    subjects: state.subjects.map((s) => (s === oldName ? n : s)),
    points: state.points.map((p) => (p.subject === oldName ? { ...p, subject: n } : p)),
  })
  return { ok: true, message: `「${oldName}」已更名为「${n}」` }
}

/** 删除科目：该科目下的知识点迁移到 moveTo */
export function deleteSubject(name: string, moveTo: string): { ok: boolean; message: string } {
  if (state.subjects.length <= 1) return { ok: false, message: '至少保留一个科目' }
  if (!state.subjects.includes(moveTo) || moveTo === name) {
    return { ok: false, message: '迁移目标无效' }
  }
  const moved = state.points.filter((p) => p.subject === name).length
  setState({
    ...state,
    subjects: state.subjects.filter((s) => s !== name),
    points: state.points.map((p) => (p.subject === name ? { ...p, subject: moveTo } : p)),
  })
  return { ok: true, message: moved > 0 ? `已删除，${moved} 个知识点移至「${moveTo}」` : '已删除' }
}

// ---------- 统计辅助 ----------

/** 连续打卡天数：今天或昨天有复习记录才开始计 */
export function studyStreak(logs: ReviewLog[]): number {
  if (logs.length === 0) return 0
  const days = new Set(logs.map((l) => startOfDay(l.reviewedAt)))
  const today = startOfDay(Date.now())
  let cursor = days.has(today) ? today : days.has(today - DAY) ? today - DAY : -1
  if (cursor < 0) return 0
  let streak = 0
  while (days.has(cursor)) {
    streak++
    cursor -= DAY
  }
  return streak
}

/** 今日已复习数量 */
export function reviewedTodayCount(logs: ReviewLog[]): number {
  const today = startOfDay(Date.now())
  return logs.filter((l) => l.reviewedAt >= today).length
}

  }
```

```typescript
/**
 * 章节感知的自然排序：
 * 识别"第X章"（X 为中文数字或阿拉伯数字，支持到 999），按章节数值排序；
 * 无章节号的标题排在有章节号的之后，其余按中文 locale + 数字感知比较
 * （保证"名词解释2"排在"名词解释10"前面）。
 */

const CN_DIGITS: Record<string, number> = {
  零: 0, 一: 1, 二: 2, 两: 2, 三: 3, 四: 4, 五: 5, 六: 6, 七: 7, 八: 8, 九: 9,
}

/** 解析中文/阿拉伯数字（0~999），无法解析返回 null */
export function parseChineseNumber(input: string): number | null {
  const s = input.trim()
  if (/^\d+$/.test(s)) return parseInt(s, 10)
  if (!s) return null
  let rest = s
  let result = 0
  let matched = false

  const bai = rest.indexOf('百')
  if (bai >= 0) {
    const h = rest.slice(0, bai)
    result += (h ? (CN_DIGITS[h] ?? NaN) : 1) * 100
    rest = rest.slice(bai + 1)
    matched = true
  }
  const shi = rest.indexOf('十')
  if (shi >= 0) {
    const t = rest.slice(0, shi)
    result += (t ? (CN_DIGITS[t] ?? NaN) : 1) * 10
    rest = rest.slice(shi + 1)
    matched = true
  }
  if (rest) {
    const d = CN_DIGITS[rest]
    if (d === undefined) {
      // 存在无法识别的尾字（如"零"以外的字符）
      if (!matched) return null
    } else {
      result += d
      matched = true
    }
  }
  if (Number.isNaN(result) || !matched) return null
  return result
}

/** 从标题提取章节号："第十六章 xxx" → 16；无章节返回 null */
export function chapterNumber(title: string): number | null {
  const m = title.match(/第\s*([一二两三四五六七八九十百零\d]+)\s*章/)
  return m ? parseChineseNumber(m[1]) : null
}

/** 章节感知比较器：先比章节号，再比标题（数字感知） */
export function naturalTitleCompare(a: string, b: string): number {
  const ca = chapterNumber(a)
  const cb = chapterNumber(b)
  if (ca !== null && cb !== null && ca !== cb) return ca - cb
  if (ca !== null && cb === null) return -1
  if (ca === null && cb !== null) return 1
  return a.localeCompare(b, 'zh-Hans-CN', { numeric: true })
}
```

```tsx
                    className="t-input h-8 text-sm"
                    autoFocus
                    onKeyDown={(e) => e.key === 'Enter' && handleRename(s)}
                  />
                  <button onClick={() => handleRename(s)} className="shrink-0 text-emerald-500">
```

```tsx
import { useState } from 'react'
import { X } from 'lucide-react'
import type { Tag } from '@/types'
import { TAG_COLORS } from '@/lib/subjectColors'
import { Input } from '@/components/ui/input'

interface Props {
  tags: Tag[]
  onChange: (tags: Tag[]) => void
}

export default function TagEditor({ tags, onChange }: Props) {
  const [text, setText] = useState('')
  const [color, setColor] = useState<string>(TAG_COLORS[0].value)

  const addTag = () => {
    const label = text.trim()
    if (!label) return
    if (tags.some((t) => t.label === label)) {
      setText('')
      return
    }
    onChange([...tags, { label, color }])
    setText('')
  }

  return (
    <div>
      {/* 颜色选择 */}
      <div className="mb-2 flex items-center gap-2">
        <span className="t-dim text-xs font-bold">颜色</span>
        {TAG_COLORS.map((c) => (
          <button
            key={c.value}
            type="button"
            onClick={() => setColor(c.value)}
            className={`h-6 w-6 rounded-full ${c.value} transition-transform ${
              color === c.value ? 'scale-110 ring-2 ring-slate-400/60 ring-offset-2' : ''
            }`}
            aria-label={c.name}
          />
        ))}
      </div>

      {/* 输入 + 添加 */}
      <div className="flex gap-2">
        <Input
          value={text}
          onChange={(e) => setText(e.target.value)}
          onKeyDown={(e) => {
            if (e.key === 'Enter') {
              e.preventDefault()
              addTag()
            }
          }}
          placeholder="输入标签名，如：名词解释"
          className="t-input"
        />
        <button
          type="button"
          onClick={addTag}
          className="t-btn shrink-0 px-4 text-sm"
        >
          贴上
        </button>
      </div>

      {/* 已有标签 */}
      {tags.length > 0 && (
        <div className="mt-2 flex flex-wrap gap-1.5">
          {tags.map((t, i) => (
            <span
              key={i}
              className={`t-chip flex items-center gap-1 px-2.5 py-1 text-xs font-bold text-white ${t.color}`}
            >
              {t.label}
              <button type="button" onClick={() => onChange(tags.filter((_, j) => j !== i))}>
                <X className="h-3 w-3" />
              </button>
            </span>
          ))}
        </div>
      )}
    </div>
  )
}
```
