# 使用与数据备份

## 首次使用

1. 管理学 A/B 教材与运动生理学最终版已内置，首页会给出第一项训练。
2. 在旧「346记忆引擎」导出 JSON，再到本版「设置数据」选择备份、查看预览、确认导入。体育概论已内置政策热点五讲（15道作业＋5组补漏查询），其他内容可继续导入或在资料库录入；旧程序的个人学习记录需要显式导入。
3. 若有 MRC 备份，可在同一入口导入。旧管理学条目保留查询，不自动转换成 MRC 成绩或重复派题。
4. 后续使用「导出全科整包」。整包包含两个模块、今日预算和未完成草稿；换浏览器或文件位置时通过整包恢复。

## 每日训练

首页只有一个开始按钮。先恢复未完成训练，再在总时间预算内安排到期复习和新学；完成后推荐下一项、等待复测或收工。每天默认60分钟；新学数量与章节配额可按科目调整。0新学表示暂停新增，0章节表示不限制章节。

预算按任务预计时长在开始时累计占用；暂停不退还预算，刷新不重复收费，跨日未完成任务占用新一天的预算。它不是精确计时。科目权重用于同级任务的时间分配，不是必须完成的硬性科目分钟数。到期任务不受新学章节上限影响，也不会绕过总预算。

首页“调整今日预算”只影响今天；设置中的“每日默认预算”同时应用到今天和后续日期。修改预算不会取消手动收工。“恢复今日训练”可显式重新开始安排，已经占用的预算、完成记录和配额不会清零。

数字设置输入后按 Enter 或离开输入框保存，Esc 撤回输入。新学数量和章节数要求整数，时间权重可使用小数。只改变权重不会重新选择今日章节。

管理学保留原提示链、Evidence、体育例证checkpoint和复测规则。通用模块保留v7.3 FSRS-6核心，并兼容V13保持率设置；先闭卷写出，再冻结草稿、核对要点和自评。通用评分与管理学Evidence分开保存。补漏记录可在后续核对成功时修复。

设置中保留管理学原版闭卷考试、方法说明及详细设置。闭卷考试是手动工具，首版不纳入全科时间预算，也不扩展成全科考试。切换页面不会暂停考试计时；结束前可以导出作答，确认结束后清除当前考试，不自动生成学习档案。

管理学用时按本轮开始时间累计，包含暂离时间；计时显示每秒更新，完成后冻结。选择另一道题时若尚有未完成训练，会先说明并允许返回当前页面，或继续原草稿。

## 查询与录入

资料库区分“没有资料”和“搜索无结果”，可清除筛选；打开题目后自动定位到详情，收起回到原题按钮。查询科目与录入草稿的科目分开：录入表单会显示保存目标，切换查询不会把草稿存错科。

未保存的教材录入草稿仅在当前页面会话内保留，可跨页面返回继续；刷新或关闭前请保存。浏览器支持时会弹出离开提醒，但不能依赖所有移动浏览器都显示提醒。未保存的录入草稿不属于全科备份；训练草稿仍按原逻辑持久保存。

管理学资料页顶部提供字号和专注阅读控制；“我的书签”可返回已收藏的题目或原文页。批注随输入自动保存，保存失败会显示提示。原文搜索遵循所选 A/B 册范围，可展开全部结果。

快捷键：Alt+1–4 切换主入口，Alt+Shift+D 切换深浅色；输入框内不生效。浏览器占用快捷键时使用页面按钮。

## 数据与回退

- 平台使用新增键 `346-fusion-platform-v1`，MRC继续使用 `pku346-recall-v1`；旧 `ms346_*_v1` 键仅读取，不改名或覆盖。
- 同浏览器能访问旧存储时可自动读取；跨本地文件共享存储依浏览器而异，推荐显式JSON导入。
- 旧JSON导入为按id合并，同id以导入值替换，预览后确认；无标题模糊匹配。训练未完成时暂停旧JSON合并，整包可以恢复未完成状态。
- “恢复整包导入前备份”位于设置的兼容与恢复折叠区，需再次确认；确认前可导出当前整包，取消或 Esc 不写数据。恢复会替换导入之后的新训练，请确认备份时间是否符合预期。
- 整包恢复替换两份模块数据，导入前保存两份原始备份；使用恢复日志处理两份存储之间的中断。
- MRC单模块导入继续调用原记录合并引擎；外围保护层保留本机考试，将备份里的草稿和考试完整归档到“管理学详细设置 → 迁移待查”，不会直接接管。需要继续备份中的训练请用全科整包。相同记录 ID 指向不同题目时拒绝合并。
- V13条目的额外字段（来源、易混组、章节等）保留在数据中；融合Alpha暂未恢复旧版易混对照、评分撤回、手动推迟、编辑/删除和预测图表界面。旧版原HTML仍可使用。
- 冻结产物：`MRC_V2.2.2_沉浸诵读冻结版.html`、`MRC_V3_Alpha_Lite.html`、`frozen/346_V13_original.html`。首次从Alpha Lite升级会接续当日预算与完成任务。

## 界面异常时

组件异常或启动恢复失败时，程序显示独立恢复页。先点击“备份原始数据”，检查下载列表，再尝试“重新打开”。原始恢复文件保留本程序已存储的两个模块、备份和事务日志，供排查使用，不能直接当作正常整包导入。

恢复文件不保证包含尚未保存的输入。读取失败的键会明确记在 `readErrors` 中；完全不能读取存储时不会生成空备份。请勿清除浏览器数据。错误边界用于 React 渲染与生命周期异常，不能兜底 HTML/脚本本身损坏或所有异步异常。

## 本次更新的使用方式

- 在「设置数据 → 内置教材修订」检查生理学或政策热点教材。逐题展开对照，默认不覆盖本地修改；只勾选确实要替换的题。更新保留评分、到期时间、批注和遗漏记录。正在训练的题需先完成后再修订。不会按标题猜测并合并不同 ID。
- 同一浏览器存储空间一次只允许一个新版窗口运行。第二窗口会显示备份与重开入口；关闭原窗口后重开即可。需支持 Web Locks 的当前版浏览器；不同浏览器/不同文件来源仍可能是不同数据空间。旧版本不会遵守新锁，升级时请关闭旧版。
- 草稿内 Ctrl+Enter 提交。通用评分页数字 1–4 只定位，Enter 才确认评分，避免误按数字直接改变复测安排。
- 管理学专注阅读隐藏侧栏与手机顶栏，使用工具条退出，或离开输入框后按 Esc。底部导航保留，防止手机失去页面出口。
- 若程序脚本损坏导致启动不了，HTML 的独立入口可备份浏览器已保存的原始记录；它不是可直接导入的正常整包，勿清除原始数据。
- 本次升级不清空个人记录。正式使用前仍建议从旧程序导出全科整包，再导入新版，确认记录后保留备份。

## PDCA 修复版的训练与迁移

通用科目选择“忘记”后，同一道题至少等待 20 分钟才会再次自动推荐；期间先安排其他符合预算与配额的题。没有其他任务时会显示等待时间，也可收工。这个间隔是透明的教练节奏规则，不是记忆概率预测；原 FSRS 的评分、日志与 dueDate 不变，管理学复测规则也不变。

教材版本变化时先保存原始管理学快照，再处理不可用题目。找不到原题的历史 Attempt 保留全文；失效的未完成草稿、整场考试和任务转入“设置数据 → 管理学详细设置 → 迁移待查”，可查看或单独导出。训练已成功保存但平台尚未结算时，会先补结算，避免错误退还预算。

迁移前备份失败会停止写入，两个模块的原始数据不会被空默认值覆盖。全科备份包含迁移待查和历史原文；旧程序已经删掉、只剩摘要的数据无法凭空重建，需更早的备份。原始迁移前快照与逐条待查下载用于保全和排查，不是全科整包；平时迁移请用“导出全科整包”。

正式使用前：在旧版导出全科备份并关闭旧版窗口，下载新版 HTML 到固定目录，用当前版 Chrome 或 Edge 打开并导入备份。核对科目、已有训练数与当前草稿，再开始当日训练。此版本不会自动清空个人记录，不必重复导入历史的零记录基线。

## 手机手写答案与离线评审

1. 先在纸上闭卷答题，拍照后用手机自带识字功能复制文字。华为双指识别是否支持具体页面，以你的机型实际操作为准；本程序不直接调用华为接口、不上传照片。
2. 在闭卷草稿框长按粘贴，交卷前校对识别错字、数字、公式和漏行。点击原有交卷按钮后原稿冻结，出现“答题评审”。手机窄屏会直接定位到评审区。
3. 优先看“待检查”：展开“我的表述与教材依据”，对照数值、方向词、否定词等提示。未匹配不等于答错，同义表述或有效的自创体育案例可由本人确认。
4. “原文对应”只说明找到原文字词，仍需确认上下文。逐项点击“我核对过，这项写到了”，或先检查批量清单再应用；已有核对项会保留。原标题清单仍可使用。程序不会根据字词匹配自动勾选、自动评分或改动复习时间。
5. 管理学点击“核对完成，去撤提示复述”；通用科目点击“核对完成，去选择回忆等级”。随后仍按原流程保存。

“原文对应”中的标题只代表骨架，不证明对应论述完整。未定位到唯一正文、资料说明或过长输入会明确交给人工核对；程序不截断原稿、不编造教材补齐。自动评审能减少逐字对照，但不能可靠裁定所有同义句、因果方向、事实错误或考试得分。

核对勾选和冻结原稿沿用原保存机制，刷新、暂停和全科备份可恢复。评审报告依据当前教材与规则重算，**不是独立存储的历史评分**；要固定保存本次依据，可在“保存评审报告与使用说明”中下载 TXT。复制权限受限时会显示报告，支持长按复制。本人确认在原核对清单中也可取消；采纳前请检查纸面原稿，不把看完答案后的补写算作闭卷输出。

闭卷考试只在揭晓答案后提供只读评审，不修改封存作答、计时或生成 Attempt。原考试清除规则不变，结束前请导出作答或需要保留的评审报告。
