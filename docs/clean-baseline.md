固定版本标签：`baseline-clean-2026-10-14`。程序沿用用户体验审计版 `45276a7`，本次只固定清理后的数据基线和发布文件，不修改应用或学习算法。

## 文件

- `346_Fusion_Alpha.html`：100项单元测试、34组离线回归通过的程序。

## 使用

1. 下载并解压基线 ZIP，用浏览器打开 HTML。
2. 在“设置数据”选择随附的 `346-Fusion-cleaned-2026-10-14.json`。
3. 检查导入预览，点击“确认整合导入”。这是整包恢复，会用基线替换当前两模块记录。
4. 导入后开始训练，之后使用“导出全科整包”保存自己的新进度；不要反复导入零记录基线。

仅更换 HTML 不会清除浏览器存储。应用仍保留原版本兼容读取逻辑，必须执行一次上述导入以应用清理后的基线；本版本不在启动时自动覆盖已有学习成果。导入器原有的导入前备份仍可用于回退，本文件不承诺对浏览器旧存储做不可恢复擦除。
